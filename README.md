# 🔐 Password Strength Checker with Breach Detection

This is a simple Python-based password checker that:
- Evaluates password strength using zxcvbn
- Checks if your password has appeared in known data breaches using the Have I Been Pwned API

## 🚀 Features
- Password strength scoring
- Real-time feedback
- Secure SHA-1 hashed breach checking
